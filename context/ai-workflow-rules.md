# AI workflow rules

Read the seven authorities in the order wired by [AGENTS](../AGENTS.md). Owner
direction controls scope; [the lifecycle library](../docs/lifecycle/LIFECYCLE.md)
controls phase gates; source and maintained tests establish implementation; dated
acceptance proves only its recorded scope. On conflict, cite sources and SHAs,
label fact versus retained evidence versus inference, and stop for Astra/high if
lineage cannot be resolved.

Activate a formal goal before editing. Preserve standalone Z-Depth identity and
the accepted `depth-sol/0.3` producer/consumer boundary. Do not reopen Phase 03 or
the frozen F1–F6 PASS, create criteria or tests to relitigate them, or turn
carried-forward results into fresh claims.

Use GPT-5.6 Terra/medium for inventory, drafting, wiring, and documentation
verification. Use one bounded GPT-6 Astra/high review for the documentation delta;
xhigh is reserved for irreconcilable lineage. Make logical documentation commits,
record commands and skips, and stop for dirty unrelated work, missing indispensable
evidence, broken links, provenance loss, product/dependency needs, credentials,
ref/stash changes, publication, deployment, history rewrite, sibling writes, or
task archival.
